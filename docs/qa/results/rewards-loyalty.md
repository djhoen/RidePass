## Headline finding
RW8 / RW11 (and the auto-program counts in RW10/RW12): the auto-enroll path stamps `enrolled_at` at finalize, but `CountQualifyingPurchases` only counts tickets with `created_at >= enrolled_at`, so the purchase that triggered auto-enrollment is excluded. Auto-enrolled riders are off by one (a count-N program needs N+1 purchases). Opt-in programs are unaffected because enrollment precedes the purchases.
